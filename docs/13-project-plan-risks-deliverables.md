# 13 — Project Plan, Risks & Deliverables

## 1. Suggested Timeline (about 3 weeks)
| Phase | Days | Output |
|---|---|---|
| Research and content | 1–3 | Brief, personas, sitemap, content inventory |
| Brand identity | 3–5 | Logo, palette, typography, guideline document |
| Wireframes and design | 5–8 | Low-fi and hi-fi screens, component library |
| Build core pages | 8–13 | Home, Products, Farmers, How It Works, Recipes, Contact |
| Animations and polish | 13–16 | Motion layer, performance tuning |
| Testing and fixes | 16–18 | QA checklist completed |
| Presentation | 19–21 | Deployed link, demo, documentation |

## 2. Risks & Mitigation
| Risk | Mitigation |
|---|---|
| Animations slow the site | Follow no-lag rules, test early, keep a reduced version |
| Heavy images | Compress, WebP, lazy-load |
| Unverified claims creep in | Content review step using file 14 |
| Scope grows | Keep backend out; list extras as future work |
| Weak imagery | Plan illustrations or licensed images early |

## 3. Future Work (not built now)
Backend and database, real order management, payments, farmer login portal, delivery tracking, CMS, Dzongkha language version.
