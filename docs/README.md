# Druk Harvest — Documentation

*From Bhutanese farms to your table.*

## Key Rules
1. Frontend only. No backend, database or payments for now.
2. Farmers are at the centre of the story.
3. Animations must be smooth (60 fps) and purposeful.
4. **No organic certification or unverified sustainability claims.** See file 14.
5. Fictional content (names, quotes, numbers) must be marked as illustrative.
