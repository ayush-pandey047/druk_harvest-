# Druk Harvest

*From Bhutanese farms to your table.*

Frontend prototype for a fictional Bhutanese farm-to-table social enterprise. Built with Vite + React, hand-written CSS and original SVG illustrations (no stock or borrowed photos).

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Pages

Home · Our Story · Products (filters, search, detail drawer, enquiry basket) · Farmers (+ profiles with scroll story) · How It Works · Recipes (+ detail) · Contact & Enquiry · Brand guide (`/brand`: logo, palette, type, social, sitemap).

Planning, design and QA documents are in [`docs/`](docs/README.md).

Farmer names, quotes, prices and contact details are illustrative placeholders for a design project.
